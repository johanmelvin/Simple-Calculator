# 🔢 Simple Calculator

A simple and responsive calculator built with HTML, CSS, and JavaScript. This project performs basic arithmetic operations and is designed for beginners learning web development.

- Addition
- Subtraction
- Multiplication
- Division
- Clear Function
- Responsive Design

## 🛠️ Built With

- CSS3
- JavaScript
